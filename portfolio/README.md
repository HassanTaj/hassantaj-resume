# Portfolio Source

This directory contains privacy-safe case studies, architectural reasoning, diagrams, screenshots, and lessons learned. It is the editorial source for deeper portfolio material; deployment remains in the separate `hassantaj.github.io` repository.

Each case study should cover:

1. Problem and context
2. Constraints
3. Architecture
4. Technology choices
5. Trade-offs
6. Implementation
7. Security
8. Operations
9. Outcome
10. Lessons learned
11. Future improvements

Do not include confidential employer/client names, internal tickets, proprietary diagrams, credentials, or private infrastructure details.
